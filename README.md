# پروپوزال امیران — توسعه ارتباط با مشتری و فروش

اسلایدهای HTML پروپوزال «پیشنهاد توسعه ارتباط با مشتری و فروش در امیران» برای فروشگاه‌های زنجیره‌ای امیران.

**دمو:** <https://amiran-proposal.vercel.app/>

یا فایل `index.html` را مستقیم در مرورگر باز کنید — دک آفلاین هم کار می‌کند.

**خروجی PDF آماده:** [`amiran-proposal.pdf`](amiran-proposal.pdf)

---

## کلیدهای میانبر

| کلید | عملکرد |
|---|---|
| `←` یا `Space` | اسلاید بعدی |
| `→` | اسلاید قبلی |
| `F` | حالت تمام‌صفحه |
| `O` | نمای کلی همه اسلایدها |
| `P` | چاپ / گرفتن خروجی PDF |
| `۱` تا `۰` | پرش مستقیم به اسلاید |
| `Home` / `End` | اولین / آخرین اسلاید |

روی موبایل و تبلت هم با کشیدن انگشت (swipe) بین اسلایدها جابه‌جا می‌شوید.
لینک هر اسلاید با هش قابل اشتراک است: `index.html#5`

---

## گرفتن خروجی PDF

۱. فایل را در Chrome یا Edge باز کنید
۲. کلید `P` را بزنید (یا `Ctrl/Cmd + P`)
۳. در تنظیمات چاپ:
 - **Layout:** Landscape
 - **Margins:** None
 - **Background graphics:** فعال
۴. Save as PDF

نسخه ساخته‌شده از قبل نیز در `amiran-proposal.pdf` موجود است.

## هویت بصری

| | |
|---|---|
| رنگ اصلی | `#c8ff0b` |
| رنگ‌های پایه | مشکی `#060606` و سفید `#ffffff` |
| فونت | [Vazirmatn](https://github.com/rastikerdar/vazirmatn) (به‌صورت محلی در مخزن) |
| نسبت تصویر | ۱۶:۹ — استیج ۱۲۸۰×۷۲۰ با مقیاس‌بندی خودکار |

دک کاملاً **آفلاین** کار می‌کند؛ فونت، لوگو و همه دارایی‌ها داخل مخزن هستند و هیچ درخواست اینترنتی زده نمی‌شود.

## دیپلوی روی Vercel

مخزن آماده دیپلوی است — سایت کاملاً استاتیک است و هیچ build stepی ندارد.
فایل `vercel.json` شامل تنظیمات cache برای فونت و دارایی‌ها است.

۱. وارد [vercel.com/new](https://vercel.com/new) شوید
۲. مخزن `amiran-proposal` را import کنید
۳. تنظیمات را دست نزنید (Framework Preset: **Other**، Build Command: خالی، Output Directory: خالی)
۴. Deploy

هر push به برنچ production یک دیپلوی جدید و هر برنچ دیگر یک **Preview URL** می‌سازد.

## ساختار فایل‌ها

```
index.html                    اسلایدها (محتوا)
amiran-proposal.pdf           خروجی PDF
assets/
  css/deck.css                دیزاین سیستم و استایل همه اسلایدها
  js/deck.js                  ناوبری، مقیاس‌بندی استیج، نمای کلی
  fonts/                      Vazirmatn (woff2)
  img/                        لوگو در سه رنگ + تصویر پیش‌نمایش شبکه‌های اجتماعی
vercel.json                   تنظیمات دیپلوی Vercel
amiran-logo.png               لوگوی اصلی آپلودشده
```

## ویرایش محتوا

تمام متن‌ها مستقیماً داخل `index.html` هستند و هر اسلاید یک `<section class="slide">` است.
برای تغییر متن کافی است همان بخش را ویرایش کنید؛ نیازی به build یا ابزار جانبی نیست.
